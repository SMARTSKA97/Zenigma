# Security policy

## Reporting a vulnerability
Please email **karmakarsubhrajit680@gmail.com** with the details and steps to reproduce. Do not open a public issue for security problems.
You can expect an acknowledgement within a few days. Please give me reasonable time to fix before disclosing.

## Scope
- Web app: https://zenigma.ska97homelab.uk
- API: https://zenigma-api.ska97homelab.uk
- Android app `uk.ska97homelab.zenigma`

Out of scope: denial of service by volume, social engineering, and findings that need a rooted device or physical access.

See [docs/SECURITY.md](docs/SECURITY.md) for how the app is hardened.
